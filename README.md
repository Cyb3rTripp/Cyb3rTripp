# Hi, I'm Tripp 👋

Cybersecurity professional focused on security operations, detection engineering, threat intelligence, and incident response. I hold a BAS in Cybersecurity from George Mason University (magna cum laude) and four GIAC certifications (GFACT, GSEC, GCIH, GCFA) — all DoD 8140/8570-approved baseline credentials — earned through the SANS Technology Institute Applied Cybersecurity Certificate.

I like building things I can break, then breaking things I can learn from — this repo is where I keep the write-ups and home-lab projects that came out of that.


## Objective

I'm looking for a role in security operations, incident response/DFIR, threat intelligence, or GRC/compliance support. I bring hands-on experience from a cybersecurity internship (threat profiling, detection-rule development in Splunk/CrowdStrike) and self-directed projects (see below). 

**U.S. citizen, eligible to obtain a security clearance.**
